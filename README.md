## 🛠️ Архитектура и Реализация виджетов (ООП + CSS Animations)

В рамках данного домашнего задания все три задачи (Collapse, Callback Chat и Liker) объединены в **единый интерактивный интерфейс (Mono-project)** для обеспечения чистоты архитектуры и высокой производительности. Каждый виджет инкапсулирован в отдельный независимый класс на чистом JavaScript.

### 📐 Спецификация компонентов:

1. **Collapse (Основное задание):** Реализован на чистом JS без использования jQuery. Высота контейнера рассчитывается динамически через `.scrollHeight` прямо в коде, что позволяет CSS-переходу (`transition: height`) отрабатывать плавно на уровне графического процессора (hardware acceleration).
2. **Liker (Задача со звездочкой):** Генератор сердечек на базе паттерна *Factory*. При клике создается элемент `img`, которому случайным образом назначается одна из **4 строго заданных траекторий** (CSS Keyframes). По завершении анимации элементы **физически удаляются из DOM** через нативное событие `animationend` для предотвращения утечек памяти (memory leaks).
3. **Callback Feedback Chat (Задача со звездочкой):** Виджет обратной связи. Переключение между круглой кнопкой FAB и формой заявки происходит с длительностью **100ms** и функцией плавности **`linear`**, как того требует регламент ТЗ.
